# Correspondence — what changed for you

- Correspondence now has an Export button in the list, same one-button experience as the other modules (Registered Order's linked Correspondence list gets the same button too).
- Export now covers the full picture, not just a handful of fields: subject, message body, type, priority, status, internal/private flags, which record it relates to, who created/updated it and when, the full To/CC recipient list, and whether it's an original message or a reply (and to which subject).
- A badge on the Correspondence menu item now shows how many messages you haven't read yet.
- Replying to a message now pre-fills the To/CC list from the original thread instead of starting blank.
- You can now select several messages and mark them all as read at once.
- If a CC recipient's name doesn't match a real user, you now get a warning instead of it silently being dropped.
- The record view has a new "History" tab showing every status change: from, to, who, and when.
- Next to the status field, a collapsed "Approval Pipeline" panel shows every possible status and who (if anyone) needs to approve it — ready for when an admin sets up a staged approval flow for this module, same as Purchase Request already has.
